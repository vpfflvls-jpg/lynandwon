# 린앤원 LYNANDWON

커플 잠옷 쇼핑몰 홈페이지입니다.

- `index.html`: 홈페이지 (한 파일로 된 사이트)
- `기획서.md`: 홈페이지 기획서
- `supabase/setup.sql`: 회원·주문 서버(Supabase)에 한 번 실행하는 설정

## 회원·주문

- 회원가입, 로그인, 메일 인증, 비밀번호 재설정은 Supabase Auth로 동작해요.
- 주문은 Supabase `orders` 테이블에 저장돼요. 회원은 마이페이지에서, 비회원은 주문번호와 휴대폰 번호로 조회해요.
- 온라인 결제는 아직 연결되지 않아 주문은 "결제 대기" 상태로 접수돼요.
- 장바구니, 찜, 상품 후기는 아직 방문자 브라우저에만 저장돼요.
